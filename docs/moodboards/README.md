# ScreenTidy Moodboards

## Purpose

This folder contains the visual inspiration for **ScreenTidy**.

These images are **references only**.

Do **not** copy layouts, screens, components, colors, or interactions
directly.

Instead, extract the underlying design principles and reinterpret them
into a unique product experience for ScreenTidy.

------------------------------------------------------------------------

# Product Context

ScreenTidy is **not**:

-   A file manager
-   A traditional photo gallery
-   A productivity dashboard
-   An enterprise application
-   A folder organizer

ScreenTidy **is**:

-   A personal memory organizer
-   An AI companion
-   Calm
-   Premium
-   Minimal
-   Apple-native
-   Content-first

Users should feel:

> "I don't have to organize anything anymore."

The AI quietly organizes everything in the background.

------------------------------------------------------------------------

# What to Learn From These Moodboards

## 1. Spacious Layouts

-   Generous whitespace
-   Comfortable spacing
-   Calm visual rhythm
-   Avoid dense information

## 2. Premium Surfaces

-   Large rounded cards
-   Soft depth
-   Minimal borders
-   Elegant shadows

## 3. Content-First

The content should create the visual richness.

The interface should remain neutral.

Avoid decorative UI.

## 4. Preview-First

Collections should be recognizable before reading their title.

For ScreenTidy, every Context Collection should display a dynamic
collage of approximately **3--4 real screenshots**.

Avoid generic folder icons.

## 5. Typography

Use Apple's system typography (SF Pro).

Prioritize:

-   Large page titles
-   Strong hierarchy
-   Minimal labels
-   Readable metadata

## 6. Color

Use a restrained palette.

Most colors should come from the screenshots themselves.

Avoid rainbow category colors.

## 7. Motion

Motion should feel:

-   Natural
-   Calm
-   Intentional
-   Subtle

Never flashy.

------------------------------------------------------------------------

# Design Principles

Every screen should feel:

-   Apple-native
-   Modern
-   Premium
-   Editorial
-   Minimal
-   Calm
-   Elegant
-   Spacious

The interface should disappear behind the content.

------------------------------------------------------------------------

# Home Screen

The Home screen is the heart of ScreenTidy.

Collections are the hero.

Preferred emotional direction:

    Good evening 👋

    I organized 12 new screenshots today.

    Japan Trip
    Apartment Setup
    Qatar Airways
    Visa Application

Do not turn Home into a dashboard full of widgets or analytics.

------------------------------------------------------------------------

# Important Rules

-   Do not copy these moodboards.
-   Extract principles, not layouts.
-   Explore multiple design directions before choosing one.
-   Keep ScreenTidy visually unique.
-   Prioritize simplicity over decoration.
-   Whenever in doubt, choose the calmer and cleaner solution.
