# ScreenTidy — Visual Direction

## Vision

ScreenTidy should feel like an Apple-designed **personal memory** product — calm AI that organized your life, not a utility that filed your screenshots.

The experience should be:
- Modern, premium, minimal, calm, spacious  
- Intelligent and content-first  
- Trustworthy (privacy-calm)  
- **Memory-like**, not folder-like  

Never feel like:
- A file manager  
- Enterprise software  
- An Android-style utility  
- A cloud drive browser  
- A taxonomy browser (“Hotels,” “Receipts” as the hero IA)

---

## Inspiration

Extract principles from moodboards — do not copy layouts:
- Large whitespace  
- Rounded cards  
- Soft shadows  
- Floating navigation  
- Premium typography  
- Screenshot previews as the visual system  

---

## Design Personality

Elegant · Friendly · Trustworthy · AI-first · Editorial · Native iOS · **Personal**

---

## Core Principles

1. AI should feel invisible.  
2. Users should feel their **life contexts** were organized for them.  
3. Screenshots are the hero.  
4. Whitespace is a feature.  
5. Simplicity over decoration.  
6. Home is a constellation of **Context Collections**, not type folders.  
7. Destructive Photos actions look serious.

---

## Layout

- 24px page padding  
- Large vertical spacing  
- One primary action per screen  
- Floating bottom navigation: Home · Search · Cleanup · Settings  

---

## Context Collection Cards (signature UI)

Each card:
- Dynamic collage of 3–4 real screenshots  
- Context title (Japan Trip, Visa Application, …)  
- Count  
- Optional insight when useful  

Do **not** use generic folder icons.  
Do **not** make Type Facets the card title system.

The collage + human context title **is** ScreenTidy’s visual identity.

---

## Navigation

- **Floating pill tab bar** (locked) — lightweight, not heavy glass  
- Rounded search bar  
- Native iOS gestures  
- Bottom sheets where appropriate  

## Home direction

**Quiet Pocket (Direction A)** — soft pocket cards with peeking screenshot stacks. Collections are the hero.  

---

## Typography

SF Pro · large headings · comfortable hierarchy · subtle metadata (facets/entities)  

---

## Colors

White / off-white / neutral gray · **primary `#008BFF`** for CTAs / selection / active nav · screenshots carry color · system red only for Photos delete  

---

## Cards

Large · rounded · soft shadow · generous padding  

---

## Motion

Natural, purposeful: hero into a context, progressive memory organization, subtle card press.  
Avoid flashy AI theatrics. Honor Reduce Motion.

---

## Empty States

Encouraging, never blank: explanation + simple illustration + one action.

---

## AI Personality (visual + copy)

Communicate:  
“I didn’t organize this.” / “The app understood what this was for.”  

Prefer context language over classification language.

---

## Privacy Visual Tone

Short, calm consent. No dark patterns around cloud AI.

---

## Design Quality Checklist

- Native iOS? Enough whitespace? Screenshots primary?  
- Does Home feel like memories/contexts (not folders)?  
- One primary action? Clear hierarchy? Consistent cards?  
- Moodboard-aligned? App Store–proud?  
- Destructive delete unmistakable?
